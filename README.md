# DecibelCity

Proyecto estudiantil para explorar el entorno acústico de Huancayo y registrar reportes de ruido con ubicaciones verificadas.

## Tecnologías

- Frontend: Angular.
- Backend: Python, FastAPI y uv.
- Base de datos: PostgreSQL.
- Mapas: Leaflet y OpenStreetMap.

## Organización

- frontend/: interfaz de usuario.
- backend/: API, validaciones y persistencia.
- Database/: modelo vigente, consultas y configuración de PostgreSQL.

Los niveles ilustrativos y las mediciones relativas del micrófono no son mediciones calibradas ni datos oficiales.

## Incorporación del proyecto

- Rama fabricio: frontend.
- Rama hans: backend y Database.
- Los cambios se incorporan a main mediante pull requests.

Las instrucciones específicas de instalación se encuentran en los README de cada carpeta cuando sus respectivos pull requests estén incorporados.
